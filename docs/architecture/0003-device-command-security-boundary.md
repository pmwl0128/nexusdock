# ADR-0003：设备命令安全边界

- 状态：Accepted
- 日期：2026-06-05
- 更新：2026-06-14

## 决策

Nexus 不提供任意 Shell。节点只执行公共协议声明、本地实现存在且设备策略允许的结构化命令，例如健康检查、Recall 同步、受控服务检查或重启、诊断、AgentDock 重载、Env 管理以及 Artifact 传输。为兼容外部 Agent，底层协议可以继续承载 Skill 生命周期命令，但 Nexus 人工界面不提供安装、运行或回滚 Skill 的入口。

人工界面只选择可理解的设备动作：

- 风险等级由命令类型固定。
- 默认有效期和重试策略由 Nexus 设置。
- 高风险动作要求明确确认。
- Env 变量只能来自设备 Runtime 上报的 Registry。
- 命令 payload 禁止携带明文 Secret。

租约过期、Token 撤销、命令过期、策略拒绝或 Handler 缺失时不得产生副作用。
